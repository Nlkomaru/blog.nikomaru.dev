# ドキュメント

## ドキュメントの作成

- アーキテクチャの変更や新しい仕様を追加した際は、必要に応じて README やドキュメントを作成・追記してください。
- なお、文章の文体について、その他の部分で指示（キャラクター口調等）があったとしても、ドキュメント・READMEに関しては、あくまでも標準的な技術文章の文体（です・ます、あるいはである調）で記載してください。
- 記事コンテンツ（MDX）の作成や更新を行う場合は、コンテンツリポジトリ `Nlkomaru/blog-content` の形式（Frontmatter: title, publishedAt, categorySlug など）に準拠してください。
